Ringkasan Eksperimen NLP

Pipeline lokal mengikuti notebook klasifikasi berita pertanian biner: data cleaning, preprocessing, lima tipe representasi teks, dan evaluasi 10 skenario model.

Ringkasan Training

Notebook menyimpan vectorizer, Word2Vec, classifier, metrik holdout, dan metadata eksperimen ke artifact dashboard.

Catatan Validasi

Dashboard membaca metrik dari artifact notebook. Model terbaik otomatis dipilih berdasarkan F1-Score holdout.

Risiko Prediksi

Input dengan kosakata di luar dataset ditolak melalui zero-vector guard. Prediksi pertanian dengan confidence rendah diberi status diragukan.

Rekomendasi

Artifact menyimpan metadata label, metrik, dan model per skenario agar dashboard bisa direproduksi dari notebook.
